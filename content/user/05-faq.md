# 常见问题

> 按现象查。每条都给「怎么确认」和「怎么办」。

## 一、登录与权限

### 登录后什么都看不到

| 可能原因 | 怎么确认 | 怎么办 |
| --- | --- | --- |
| 账号没绑定客户 | 左侧「场站」为空，但能进系统 | 联系租户管理员，把账号绑到客户 |
| 客户下还没建场站 | 设备页也是空的 | 先建场站，或联系平台方导入 |
| 账号是只读角色 | 能看到数据但没有新建按钮 | 需要编辑权限就找管理员改角色 |

### 能登录，但看不到某个场站

- 场站没挂到你的客户下
- 场站挂在别的客户下（这是隔离，不是故障）

### 提示「没有权限执行此操作」

客户的权限边界是**自己名下的数据**。访问其他客户或租户级接口都会 403，这是设计如此。

## 二、数据不显示

### 设备列表有，但「最新遥测」是空的

按顺序查：

1. **网关在线吗** —— 网关设备页看最后活跃时间
2. **RTU 配的点位对吗** —— 点位地址、倍率是否与表计说明书一致
3. **键名是标准键名吗** —— `Ua` 不会被识别成 `voltage_a`
4. **上报主题对吗** —— 必须是 `v1/devices/me/telemetry`
5. **payload 是合法 JSON 吗**

### 某个参数列全是空的

这个点位没配。比如「相电压」里 B 相空白，说明没配 `voltage_b`。这是数据缺失，不是平台算错。

### 分析页有数据，但分项能耗是空的

- 设备没填「分项」
- 或分项没有双挂（场站 + 能源品种）

分项必须同时挂两处，缺一处统计不到。用导入脚本建会自动双挂。

### 刚接完设备，AI 预测页是空的

正常。AI 需要至少 14 天历史数据。见[换成自己的数据](/user/onboarding) 第八节。

## 三、数字不对

### 电量差 10 倍或 100 倍

倍率配错。Modbus 寄存器是整数，平台期望浮点：

```
表计读到 2283，倍率 0.1  →  228.3 V   ✅
表计读到 2283，倍率 1    →  2283 V    ❌
```

### 电量比实际电费单多一倍

大概率是同时上报了 `energy_reading` 和 `energy`。两者只能选一个：

- 累计表底 → 只填 `energy_reading`
- 本周期增量 → 只填 `energy`

### 总分对不上

检查「层级」配置：

```
level=1  总表
level=2  分表
level=3  支路
```

上层之和小于下层之和 → 层级配反了。
上层之和大于下层之和 → 正常，差额是未装表的回路。

### 电费与供电局账单对不上

电价方案没配全。平台按租户的 `tou_scheme` 算，没配就用默认值。默认值与你的实际电价方案可能不同，需在「基础配置中心」里按实际电价改。

### 同比/环比数字奇怪

本月没过完时，同比是**与上月同期**比，不是与上月全月比。

## 四、图表看不懂

### 能源流向图末端有缺口

这是**有回路没装表**，缺口就是不明损耗。正常应小于 10%。想消掉就补装表计。

### 三相不平衡一直很高

单相设备（照明、插座、空调）挂得不均。把部分单相负载调到其他相上即可。

### 功率因数低于 0.9

会被供电局罚款。加装无功补偿电容，或检查现有补偿柜是否正常投运。

### 峰谷占比和电费单对不上

电价方案的时段划分与当地不一致。检查「基础配置中心 → 电价方案」。

## 五、操作类

### 怎么新增一台设备

「设备 → 新增」，必须选：

- 所属客户
- 设备档案（决定采集什么）
- 名称（租户内唯一）

建完后还要挂到资产树，并设置 `level` 属性，否则不出现在分析页。

### 怎么改设备的场站归属

设备详情 → 编辑 → `additionalInfo` 里的 `siteId` 改成目标场站 ID。

### 怎么删演示数据

演示数据的 `additionalInfo` 里有 `demo=true` 标记。在「基础配置中心」有「清理演示数据」入口，只删带标记的，不碰你自建的数据。

### 怎么导出报表

各报表页右上角有「导出」，选 Excel 或 CSV。

## 六、术语表

| 词 | 意思 |
| --- | --- |
| **场站** | 物理地点（厂房、楼栋、配电室）。所有分析的边界 |
| **组织** | 企业管理层级（集团、分公司）。不承载用能数据 |
| **分项** | 按用途分类：动力、照明、空调 |
| **区域** | 按功能分区：生产区、办公区、仓储区 |
| **空间位置** | 按物理位置：3 楼东侧、厂区北侧 |
| **层级（level）** | 1 总表 / 2 分表 / 3 支路，决定总分关系 |
| **设备档案** | 决定这台设备采集什么数据（电能表、水表…） |
| **能源品种** | 电、水、燃气、蒸汽 |
| **标准键名** | 平台认可的参数名，如 `voltage_a` |
| **倍率** | 把寄存器整数换成实际值的系数 |
| **RTU** | 现场采集终端，读表计并上报平台 |
| **accessToken** | 设备的接入码，凭它上报数据 |
| **折标煤** | 把不同能源换算成统一单位（吨标准煤） |
| **THD** | 谐波总畸变率，衡量电能质量 |
| **需量** | 一段时间内的最大功率，影响基本电费 |
| **力调电费** | 功率因数不达标产生的罚款/奖励 |

## 七、还是解决不了

把这三样发给平台方，能大幅加快定位：

1. **哪个页面** + 截图
2. **哪台设备** + 设备名称
3. **「设备 → 最新遥测」里该设备的数据**（有值还是空）

如果需要平台方查日志，再补一条：问题发生的大致时间。
