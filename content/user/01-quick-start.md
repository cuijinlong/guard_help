# 5 分钟上手

> 从登录到看懂第一屏。照着做，不用记。

## 第 1 步：登录

浏览器打开平台地址（平台方会给），输入邮箱和密码。

```
地址：http://你的平台地址/
账号：客户管理员给你的邮箱
密码：首次登录时设的密码
```

**登录后你会看到**：顶部菜单 + 左侧导航 + 中间内容区。

## 第 2 步：确认能看到自己的数据

点左侧「场站」，应该能看到属于你的场站列表。

| 情况 | 说明 |
| --- | --- |
| 看到场站列表 | 正常，继续 |
| 显示「暂无数据」 | 你的账号还没绑定客户，或客户下还没建场站。联系租户管理员 |
| 看到别人的场站 | 这是故障，立即联系平台方 |

## 第 3 步：打开第一个页面

点左侧「能耗概览」。这是默认首页，一屏看完整体情况：

```
┌─────────────────────────────────────────────┐
│  本月用电量    │  本月电费   │  同比   │  环比  │  ← 四个 KPI
├─────────────────────────────────────────────┤
│                                             │
│      24 小时负荷曲线（今天的用电趋势）        │
│                                             │
├──────────────────────┬──────────────────────┤
│  分项占比（饼图）      │  区域排名（柱状图）     │
└──────────────────────┴──────────────────────┘
```

**怎么读**：

- **KPI 卡片**：本月累计、与上月/去年同期对比。箭头向上是增加
- **负荷曲线**：横轴是今天 0–24 点，纵轴是功率（kW）。曲线应该有明显的生产/休息节律
- **分项占比**：动力、照明、空调各占多少。如果只有一项 100%，说明设备没分项
- **区域排名**：哪个车间/楼栋用电最多

> 如果这一屏全是 0 或空白，见[常见问题](/user/faq) 的「登录后看不到数据」。

## 第 4 步：下钻一次

在「分项占比」饼图上点「动力」，页面会切到动力分项明细。

这就是这套系统的核心操作：**点任何图表的某一块，都会下钻到那一块对应的设备清单**。

## 第 5 步：看一台设备的原始数据

1. 左侧「设备」
2. 找到任意一台设备，点进去
3. 切到「最新遥测」标签

你会看到这张表最近上报的所有点位：

```
时间                  键名                值
2026-10-20 14:00     energy_reading      12345.6
2026-10-20 14:00     voltage_a           228.3
2026-10-20 14:00     current_a           15.2
2026-10-20 14:00     power_total         3.4
```

**这一页是排障的起点**：分析页数字不对时，先来这里看原始值是否正确。

## 第 6 步：认一下导航

左侧导航按用途分成六组：

| 分组 | 页面 | 什么时候用 |
| --- | --- | --- |
| **总览** | 能耗概览 | 每天第一眼看整体 |
| **能耗分析** | 实时能耗、历史能耗、分项能耗、区域能耗、峰谷分析、综合能耗、能源流向 | 找问题、做对比 |
| **报表** | 参数报表、基础报表、手工填报、抄表功能 | 出正式数据、补录 |
| **专项** | 电能质量、能耗洞察、节能记录、盘查报告、闲时能耗 | 深入诊断 |
| **设备** | 设备、设备分组、设备运维 | 看设备、查采集 |
| **配置** | 基础配置中心、客户能源档案、厂商与型号 | 改基础数据 |
