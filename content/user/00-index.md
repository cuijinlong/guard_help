# 开始之前

> 三分钟读懂这套系统是干什么的、你该看哪一页。

## 一、它解决什么问题

工厂、园区、商业楼宇的用电用能，通常卡在三件事上：

1. **不知道钱花在哪** —— 电费单只有一个总数，说不清是车间还是空调
2. **不知道有没有异常** —— 三相不平衡、功率因数低、夜间空转，都是隐形的浪费
3. **不知道能省多少** —— 想改但算不出收益，改完也验证不了

这套系统把这三件事变成可查的数字：**从总表一路下钻到每台设备，每个小时用在哪里、用得好不好、能省多少**。

## 二、它包含什么

| 能力 | 具体是什么 |
| --- | --- |
| 采集 | 通过 RTU 网关接电表、水表、燃气表、蒸汽表、温湿度传感器 |
| 组织 | 按组织 → 场站 → 区域/分项 建立你的用能结构 |
| 分析 | 18 个分析页面：概览、分项、区域、历史、峰谷、电能质量、能源流向… |
| 报告 | 参数报表、盘查报告、节能记录、账单 |
| 预警 | 告警规则 + 告警中心 |
| 预测 | AI 负载预测（需要至少 14 天历史数据） |

## 三、你属于哪类用户

系统有四种角色，看到的东西不一样：

| 角色 | 看到的数据范围 | 典型使用者 |
| --- | --- | --- |
| 系统管理员 | 全平台所有租户 | 平台运营方 |
| 租户管理员 | 本租户所有客户 | 集团能源管理部门 |
| 客户用户 | 只看到自己名下的场站与设备 | 厂区能源负责人 |
| 只读用户 | 同客户用户，但只能看不能改 | 巡检、审计人员 |

> **注意**：客户用户看不到其他客户的数据，这是系统隔离的硬边界。
> 如果你发现能看到别人的场站，那是故障，不是权限问题，请联系平台方。

## 五、两个必须记住的前提

**① 没有场站，所有报表都是空的。**
场站是一切分析的边界。设备必须挂到场站下，否则它在任何页面都不会出现。

**② 数据质量决定分析质量。**
如果 RTU 少配一个点位（比如漏了 `voltage_b`），对应那一列就是空的 —— 系统不会编造数据。看到空白先查采集，不要先怀疑平台。
