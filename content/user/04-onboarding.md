# 换成自己的数据

> 把演示数据换成你自己的场站和设备。只需要填三张表。

## 一、你会经历什么

```
你填 3 张表（15–30 分钟）
      ↓
交给平台方，一条命令导入（1 分钟）
      ↓
拿到每台设备的接入码（平台方给）
      ↓
现场按清单配 RTU 网关（10 分钟）
      ↓
数据开始上报，所有页面自动有内容
```

**你不需要在界面上一个个点。** 场站、分组、分项、区域、设备、拓扑，全部由导入脚本按你填的表自动建好。

## 二、三张表分别是什么

| 表 | 一行代表 | 你要填的是 |
| --- | --- | --- |
| **场站** | 一个场站 | 你有哪几个厂房/楼栋/配电室 |
| **设备** | 一台表计 | 每个场站下有哪些表，各是什么类型 |
| **点位** | 一个采集点 | 每台表采集哪些数据，RTU 地址是多少 |

## 三、表一：场站

```csv
客户名称,场站名称,场站分组,用能区域,空间位置,用能性质,备注
星河工业园,1号厂房,A区,生产区,厂区北侧,生产用能,
星河工业园,2号厂房,,生产区,厂区南侧,生产用能,
```

**怎么填**：

- `场站名称`：按物理边界填 —— 楼栋、车间、配电室。**不要按设备类型填**
- `场站分组`：如果厂房有片区划分就填，没有留空
- `用能区域` / `空间位置` / `用能性质`：留空也能用，填了「区域能耗」等页面才有数据

**命名建议**：带地点信息，如 `1号厂房`、`东区泵站`。不要用 `场站001`。

## 四、表二：设备

```csv
设备名称,所属场站,设备档案,层级,厂商,型号,分项,用能区域,空间位置,用能性质,备注
1号厂房-进线总表,1号厂房,电能表,1,威胜,DTSD341,动力分项,生产区,厂区北侧,生产用能,
1号厂房-照明回路,1号厂房,单相电能表,3,威胜,DDZY102,照明分项,生产区,厂区北侧,生产用能,
2号厂房-空压站表,2号厂房,电能表,2,安科瑞,ACREL DTSD1352,动力分项,生产区,厂区南侧,生产用能,
2号厂房-温湿度,2号厂房,温湿度变送器,3,,,,生产区,厂区南侧,生产用能,
```

### 设备档案（必填，决定采集什么）

| 档案 | 什么时候用 |
| --- | --- |
| `电能表` | 三相四线表（车间动力、进线柜） |
| `单相电能表` | 单相两线表（照明、插座回路） |
| `水表` / `燃气表` / `蒸汽表` | 对应的表计 |
| `温湿度变送器` | 温湿度传感器 |
| `网关` | RTU 网关本体 |

### 层级（必填，决定总分关系）

| 值 | 含义 | 举例 |
| --- | --- | --- |
| `1` | 总表（进线） | 厂区进线柜的表 |
| `2` | 分表（车间/楼层） | 车间配电柜的表 |
| `3` | 支路表（末端回路） | 单台设备、单条照明的表 |

**层级的实际作用**：平台靠它做总分核对。上层之和减去下层之和，差额就是「没装表的回路」—— 这个数字本身很有价值。

### 分项（选填，但强烈建议填）

分项是「这个电用来干什么」：`动力分项`、`照明分项`、`空调分项`。

不填的后果：「分项能耗」页面这一项显示为空，钱花在哪就说不清了。

### 厂商 / 型号（选填）

填了之后，设备台账、按厂商统计才有数据。留空不影响采集。

名称必须与平台「厂商与型号」里已有的完全一致，否则会提示找不到。

## 五、表三：点位（最容易填错）

```csv
设备名称,标准键名,点位地址,倍率,单位,备注
1号厂房-进线总表,energy_reading,40001,0.01,kWh,正向有功总电度
1号厂房-进线总表,voltage_a,40010,0.1,V,A相电压
1号厂房-进线总表,current_a,40016,0.001,A,A相电流
1号厂房-进线总表,power_total,40028,0.001,kW,总有功功率
```

### 标准键名（平台认的名字）

**电表常用**：

| 键名 | 含义 | 单位 |
| --- | --- | --- |
| `energy_reading` | 正向有功总电度（表底） | kWh |
| `energy` | 本周期用电量（增量） | kWh |
| `energy_peak` / `energy_flat` / `energy_valley` | 峰/平/谷电度 | kWh |
| `voltage_a` / `voltage_b` / `voltage_c` | 三相电压 | V |
| `current_a` / `current_b` / `current_c` | 三相电流 | A |
| `power_total` | 总功率 | kW |
| `power_factor_total` | 总功率因数 | — |
| `frequency` | 频率 | Hz |

**温湿度**：`temperature`（℃）、`humidity`（%）

**水/气/汽**：`energy`（用量）、`energy_reading`（表底）、`power`（瞬时流量）

### 三个必须注意的点

**① `energy` 和 `energy_reading` 只能选一个**

- 表计给的是**累计表底** → 填 `energy_reading`，平台自动做差
- 表计给的是**本周期增量** → 填 `energy`

两个都填会**重复计量**，电量直接翻倍。

**② 单相表只填 A 相**

单相表没有 B/C 相。填了会被跳过，但建议根本不填，避免误会。

**③ 倍率必须照抄表计说明书**

Modbus 寄存器通常是整数，平台期望浮点。倍率填错，数据差 10 倍或 100 倍。

例：表计读到 `2283`，倍率 `0.1`，平台显示 `228.3 V`。

## 六、填完后怎么做

1. 把三张表交给平台方（或直接给 agent）
2. 平台方会先跑一次校验，有问题会**逐行告诉你哪一行错了**
3. 校验通过后正式导入
4. 平台方给你一份 **RTU 配置清单**（含每台设备的接入码）
5. 把这份清单交给现场电工/集成商配网关

## 七、现场配网关要做什么

现场只需要照清单配三样：

| 配置 | 值 |
| --- | --- |
| 平台地址 | 平台方给 |
| 设备接入码 | 清单里的 `accessToken` |
| 点位映射 | 清单里的「点位地址 → 标准键名」 |

再加一条采集周期建议：

| 数据 | 周期 |
| --- | --- |
| 电度 | 15 分钟 |
| 电压/电流/功率 | 1 分钟 |
| 温湿度 | 5 分钟 |

配完在平台「设备 → 最新遥测」能看到数据，就成功了。

## 八、多久能看到完整分析

| 时间 | 能看到什么 |
| --- | --- |
| 立刻 | 实时能耗、设备最新遥测 |
| 1 小时后 | 负荷曲线 |
| 1 天后 | 日对比、分项占比 |
| 7 天后 | 周趋势、峰谷分析 |
| **14 天后** | **AI 负载预测可用** |
| 30 天后 | 月度同比、节能验证 |

> AI 预测需要至少 14 天历史。刚接完的两周内预测页是空的，这是正常的。
