# 换成自己的数据

> 建场站、接设备、划分项、出第一份报告。这是客户真正上手的一篇。

## 本页内容（大纲待确认）

- 第 0 步：先想清楚边界（哪些场站、哪些表）
- 第 1 步：建组织与场站（组织 → 新增场站）
- 第 2 步：接设备
  - 有网关：网关接入 → 添加下游设备
  - 有电表直连：设备接入
  - 没有硬件：先用虚拟汇总点
- 第 3 步：把设备挂到分区/分项
- 第 4 步：配置能源品种与倍率
- 第 5 步：验证数据能上来（看实时能耗）
- 第 6 步：出第一份综合能耗
- 常见卡点：设备在线但没数据、数据有了但报表是空的
