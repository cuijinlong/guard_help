## 本页内容（大纲待确认）

- 整体拓扑：浏览器 → TB(8090) → PostgreSQL；浏览器 → ngx-ai 前端(18800) → ngx-ai 后端(18801) → TB
- ThingsBoard 承担的角色：实体、遥测、RBAC、仪表板、规则链
- ngx-ai 承担的角色：预测、建议、异常、用能质量
- 为什么分析平台不单独存业务主数据（TB 是主数据源）
- 数据流向：设备 → MQTT/HTTP → 规则链 → ts_kv → 部件查询
- 自定义部件在哪：widget_bundles / widget_types 表 + 部件源码仓库
